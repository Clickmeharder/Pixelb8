Hosted Clan Feed Setup

Deploy your clan feed

Your clan feed runs in your own free Cloudflare account, so its traffic and free quota stay separate from PixelB8 and other clans.

1

Connect GitHub to Cloudflare

Open the Cloudflare setup once and choose New GitHub connection. Authorize the Cloudflare Workers & Pages GitHub app for the GitHub account you want to use. When the connection finishes, you can close that Cloudflare tab and return here.

Connect GitHub to Cloudflare

This is a one-time connection for your Cloudflare account. After your clan feed is deployed, you can restrict Cloudflare's GitHub access to only the new clan-feed repo.

2

Deploy the PixelB8 clan feed

Open the deploy page again and select the GitHub account you just connected. Keep Create private Git repository enabled and set the project name to your-clan-feed-cloudflare-setup.

Deploy Clan Feed

Leave Preview Builds off and leave Protect with Cloudflare Access off. Cloudflare will create the private deployment repo for you.

3

Limit GitHub access

After deployment, you can open GitHub's installed-app settings and change Cloudflare Workers & Pages to Only select repositories, selecting only your new clan-feed repo.

Manage GitHub App Access
4

Save your deployed feed URL

After Cloudflare finishes, copy the Worker URL it gives you. Close this guide, paste the secure wss:// feed URL into the field below, and press Save Feed URL.
